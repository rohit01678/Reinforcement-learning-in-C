# Reinforcement-learning-in-C
This is just a common implementation of reinforcement learning with C language .It involves building an autonomous decision-making system from first principles without relying on heavy machine learning frameworks like PyTorch or TensorFlow. This is not advance Reinforcement learning but it gives a common idea about reinforcement learning .
# Snake.c
this file contain all the code related to the memory allocation,Random number generation,I use a snake game environment to show the reinforcement you can apply a different approach if you like.
# compilation
I use mingw64 for this code feel free to use anything you want.
